# Fuentes de audio cantado

La app ya sintetiza tropos. Para el **texto cantado** usa:

1. **Grabación de tu rabino / baal koreh** (mejor opción pedagógica) — micrófono o archivo, en la sección de grabaciones comunitarias.
2. **Tu propia toma** para compararte.
3. Fuentes públicas (no se embeben todas; descarga y respeta términos):

| Fuente | Qué es | Uso |
| --- | --- | --- |
| [Mechon Mamre / Talking Bibles](https://www.mechon-mamre.org/p/pt/ptmp3prq.htm) | Hebreo hablado por capítulo, HTTPS | Pronunciación; no es cantileo |
| [Sephardic Hazzanut](http://www.sephardichazzanut.com/) | Cantado por Aliá (sefardí), HTTP | Descargar MP3 y subir |
| [tikkun.io](https://www.tikkun.io) | Tikkun + audio | Respeta términos; no scrapear |

No hay una API abierta y libre de leyning Ashkenazi completo para embeber en bloque. Por eso la plataforma prioriza **grabaciones de la comunidad**.
